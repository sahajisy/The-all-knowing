# Library / 本棚

Drop your own documents here — articles, notes, book excerpts, PDFs (`.md`, `.txt`, `.pdf`).
Then type `/read <filename>` and Sarva will discuss it with you, connecting its ideas
to everything else you've talked about.

**Privacy:** everything in this folder except this README is git-ignored, so articles you
download (for example from The Wikipedia Library, which licenses them to you personally)
stay on your computer and are never pushed to GitHub.
