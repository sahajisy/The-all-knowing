---
description: Find hidden links between two seemingly unrelated things
argument-hint: <thing A> <thing B>
---

Connect these: **$ARGUMENTS**

If only one thing was given, pick a surprising partner for it from a distant domain.

Build a "chain of connections" (連想ゲーム) from A to B in 3–6 hops, where each hop is a
real, explainable link (shared history, same underlying principle, a person who bridges
them, a word etymology, a common mathematical structure, etc.).

Present the chain one or two hops at a time and invite the user to guess the next link
before revealing it. Finish by asking whether they can find a *different* path.

Use `knowledge/connections.md` for inspiration. If you discover a great new chain,
note it so `/wrap` can add it there.
